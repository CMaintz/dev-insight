## Purpose
The adapters behind the Application layer's ports (PostgreSQL via EF Core, GitHub via Octokit, the git CLI, the Anthropic API, an in-process run queue and its background workers), plus the port interfaces, shared exceptions and ownership helper, and the DI registration that wires them together (`backend/src/DevInsight.Infrastructure/DevInsight.Infrastructure.csproj`, `backend/src/DevInsight.Application/Abstractions/Ports.cs`, `backend/src/DevInsight.Application/Abstractions/Stores.cs`, `backend/src/DevInsight.Infrastructure/DependencyInjection.cs#DependencyInjection.AddInfrastructure`).

## Features
- Port contracts the use cases depend on: GitHub API, repository snapshot capture, encrypted credential storage, optional AI feedback, the analysis queue (`backend/src/DevInsight.Application/Abstractions/Ports.cs#IGitHubGateway`, `backend/src/DevInsight.Application/Abstractions/Ports.cs#IRepositorySnapshotSource`, `backend/src/DevInsight.Application/Abstractions/Ports.cs#IGitHubCredentialStore`, `backend/src/DevInsight.Application/Abstractions/Ports.cs#IAiFeedbackGenerator`, `backend/src/DevInsight.Application/Abstractions/Ports.cs#IAnalysisQueue`), and per-aggregate stores plus a unit of work (`backend/src/DevInsight.Application/Abstractions/Stores.cs#IUnitOfWork`, `backend/src/DevInsight.Application/Abstractions/Stores.cs#IAnalysisStore`).
- EF Core stores implementing those contracts, all sharing one scoped `DevInsightDbContext` that is also the `IUnitOfWork` (`backend/src/DevInsight.Infrastructure/Persistence/Stores/EfStores.cs#EfUserStore`, `backend/src/DevInsight.Infrastructure/Persistence/Stores/EfStores.cs#EfRepositoryStore`, `backend/src/DevInsight.Infrastructure/Persistence/Stores/EfStores.cs#EfAnalysisRunStore`, `backend/src/DevInsight.Infrastructure/Persistence/Stores/EfStores.cs#EfProjectStore`, `backend/src/DevInsight.Infrastructure/Persistence/Stores/EfAnalysisStore.cs#EfAnalysisStore`, `backend/src/DevInsight.Infrastructure/DependencyInjection.cs#DependencyInjection.AddPersistence`).
- GitHub OAuth login URL, code-for-token exchange, identity with verified emails, repository listing (private repos filtered unless `IncludePrivateRepositories`) and language breakdown (`backend/src/DevInsight.Infrastructure/GitHub/OctokitGitHubGateway.cs#OctokitGitHubGateway`, `backend/src/DevInsight.Infrastructure/GitHub/GitHubOptions.cs#GitHubOptions.IncludePrivateRepositories`).
- Repository snapshot by a single-branch `git clone` into a temp directory: HEAD sha, `git log --numstat` capped at `MaxCommits`, and line counts of text files up to 2 MB; repos over `MaxRepositorySizeMb` are rejected and the clone is deleted afterwards (`backend/src/DevInsight.Infrastructure/Git/GitSnapshotSource.cs#GitSnapshotSource.CaptureAsync`, `backend/src/DevInsight.Infrastructure/Git/GitSnapshotSource.cs#GitAnalysisOptions`, `backend/src/DevInsight.Infrastructure/Git/GitLogParser.cs#GitLogParser.Parse`).
- The token reaches git as an `http.extraheader` via `GIT_CONFIG_*` env vars, and git runs with argument lists and terminal prompts disabled (`backend/src/DevInsight.Infrastructure/Git/GitSnapshotSource.cs#GitSnapshotSource.CloneAsync`, `backend/src/DevInsight.Infrastructure/Git/GitProcess.cs#GitProcess.StartInfo`).
- AI feedback from Claude using a JSON-schema structured output; disabled when `AiFeedback:ApiKey` is empty, and refusals, rate limits and API errors yield no findings (`backend/src/DevInsight.Infrastructure/Ai/ClaudeFeedbackGenerator.cs#ClaudeFeedbackGenerator.GenerateAsync`, `backend/src/DevInsight.Infrastructure/Ai/ClaudeFeedbackGenerator.cs#ClaudeFeedbackGenerator.BuildRequest`, `backend/src/DevInsight.Infrastructure/Ai/AiFindingsParser.cs#AiFindingsParser.Parse`).
- GitHub tokens encrypted with ASP.NET Core Data Protection (purpose `DevInsight.GitHubToken.v1`), with the key ring persisted in the same database (`backend/src/DevInsight.Infrastructure/Security/ProtectedGitHubCredentialStore.cs#ProtectedGitHubCredentialStore`, `backend/src/DevInsight.Infrastructure/DependencyInjection.cs#DependencyInjection.AddPersistence`).
- Shared plumbing: UUIDv7 ids (`backend/src/DevInsight.Domain/Common/Ids.cs#Ids.New`), the `IUserOwned` marker and `OwnedBy` check that turns another user's entity into `NotFoundException` (`backend/src/DevInsight.Domain/Common/IUserOwned.cs#IUserOwned`, `backend/src/DevInsight.Application/Common/Errors.cs#Ownership.OwnedBy`), and the exception types the API maps to 404 / 400 / 412 (`backend/src/DevInsight.Application/Common/Errors.cs#NotFoundException`, `backend/src/DevInsight.Domain/Common/DomainException.cs#DomainException`, `backend/src/DevInsight.Application/Common/Errors.cs#PreconditionFailedException`, `backend/src/DevInsight.Api/Infrastructure/ProblemDetailsExceptionHandler.cs`).

## Owned entities
- `DevInsightDbContext`: the EF Core context, `DbSet`s for users, repositories, analyses, analysis metrics, feedback, analysis runs, projects, GitHub credentials and data-protection keys; enum properties stored as strings (`backend/src/DevInsight.Infrastructure/Persistence/DevInsightDbContext.cs#DevInsightDbContext`, `backend/src/DevInsight.Infrastructure/Persistence/DevInsightDbContext.cs#DevInsightDbContext.ConfigureConventions`).
- Entity mappings: keys, unique indexes (`github_id`; `(user_id, github_repo_id)`; `(analysis_id, name)`), cascade deletes, length limits, and `jsonb` columns for value-object collections (`backend/src/DevInsight.Infrastructure/Persistence/Configurations/EntityConfigurations.cs#RepositoryConfiguration`, `backend/src/DevInsight.Infrastructure/Persistence/Configurations/EntityConfigurations.cs#AnalysisConfiguration`, `backend/src/DevInsight.Infrastructure/Persistence/Configurations/EntityConfigurations.cs#UserConfiguration`, `backend/src/DevInsight.Infrastructure/Persistence/JsonColumn.cs#JsonColumn.HasJsonConversion`).
- `GitHubCredential`: the one entity this slice defines, and stores through its credential store; the only writer is sign-in in api-auth. Keyed by user id in `github_credentials`, holding the protected token (`backend/src/DevInsight.Infrastructure/Persistence/DevInsightDbContext.cs#GitHubCredential`, `backend/src/DevInsight.Infrastructure/Persistence/Configurations/EntityConfigurations.cs#GitHubCredentialConfiguration`, `backend/src/DevInsight.Infrastructure/Security/ProtectedGitHubCredentialStore.cs#ProtectedGitHubCredentialStore.SaveAsync`).
- Data-protection keys, via `IDataProtectionKeyContext` (`backend/src/DevInsight.Infrastructure/Persistence/DevInsightDbContext.cs#DevInsightDbContext.DataProtectionKeys`).
- Schema: a single migration with snake_case tables (`backend/src/DevInsight.Infrastructure/Persistence/Migrations/20260927213310_InitialCreate.cs#InitialCreate`, `backend/src/DevInsight.Infrastructure/Persistence/Migrations/DevInsightDbContextModelSnapshot.cs`).

## Happy paths
### Startup wiring and migration
1. Entrypoint: the API host registers `AddApplication()` then `AddInfrastructure(configuration)` (`backend/src/DevInsight.Api/Program.cs`).
2. `AddApplication` registers `TimeProvider.System` as a singleton and the use-case classes as scoped services (`backend/src/DevInsight.Application/DependencyInjection.cs#DependencyInjection.AddApplication`).
3. `AddPersistence` registers the context with Npgsql and snake_case naming, resolving `ConnectionStrings:DevInsight` lazily and throwing if empty; binds `IUnitOfWork` to the context; registers the EF stores, the protected credential store and Data Protection (`backend/src/DevInsight.Infrastructure/DependencyInjection.cs#DependencyInjection.AddPersistence`, `backend/src/DevInsight.Infrastructure/DependencyInjection.cs#DependencyInjection.RequiredConnectionString`).
4. `AddExternalServices` binds the `GitHub`, `GitAnalysis` and `AiFeedback` config sections and registers the gateway, snapshot source and AI generator as singletons (`backend/src/DevInsight.Infrastructure/DependencyInjection.cs#DependencyInjection.AddExternalServices`).
5. `AddAnalysisWorker` binds `AnalysisWorker`, registers the singleton channel queue and the two hosted services (`backend/src/DevInsight.Infrastructure/DependencyInjection.cs#DependencyInjection.AddAnalysisWorker`).
6. When `Database:MigrateOnStartup` is true (the default), the host applies EF migrations before running (`backend/src/DevInsight.Api/Program.cs`, `backend/src/DevInsight.Api/appsettings.json`).

### Queued analysis run executed to completion
1. Entrypoint: `POST /run/{repoId}` under the analysis group calls `RequestAnalysis.ExecuteAsync` (`backend/src/DevInsight.Api/Endpoints/ApiEndpoints.cs`, `backend/src/DevInsight.Application/Analyses/RequestAnalysis.cs#RequestAnalysis.ExecuteAsync`).
2. If an unfinished run exists for the repo and scope it is returned; otherwise a `Queued` run is added, saved, then its id written to the channel (`backend/src/DevInsight.Infrastructure/Persistence/Stores/EfStores.cs#EfAnalysisRunStore.FindUnfinishedAsync`, `backend/src/DevInsight.Domain/Analyses/AnalysisRun.cs#AnalysisRun.Queue`, `backend/src/DevInsight.Infrastructure/AnalysisRuns/AnalysisWorker.cs#ChannelAnalysisQueue.EnqueueAsync`).
3. `AnalysisWorker` (when `Enabled`) first re-queues runs left `Queued`/`Running` by a previous process, then drains the channel with up to `MaxConcurrency` parallel runs, each in its own DI scope calling `RunAnalysis.ExecuteAsync` and logging unhandled errors (`backend/src/DevInsight.Infrastructure/AnalysisRuns/AnalysisWorker.cs#AnalysisWorker.ExecuteAsync`, `backend/src/DevInsight.Infrastructure/AnalysisRuns/AnalysisWorker.cs#AnalysisWorker.RecoverUnfinishedRunsAsync`, `backend/src/DevInsight.Domain/Analyses/AnalysisRun.cs#AnalysisRun.Requeue`).
4. `RunAnalysis` skips non-`Queued` runs, marks the run `Running` and saves, then loads repository, user and decrypted token (`backend/src/DevInsight.Application/Analyses/RunAnalysis.cs#RunAnalysis.ExecuteAsync`, `backend/src/DevInsight.Domain/Analyses/AnalysisRun.cs#AnalysisRun.Start`, `backend/src/DevInsight.Infrastructure/Security/ProtectedGitHubCredentialStore.cs#ProtectedGitHubCredentialStore.GetAsync`).
5. External call: git clone and log through `GitSnapshotSource` (`backend/src/DevInsight.Infrastructure/Git/GitSnapshotSource.cs#GitSnapshotSource.CaptureAsync`, `backend/src/DevInsight.Infrastructure/Git/GitProcess.cs#GitProcess.RunAsync`).
6. Domain analysis and rule feedback are computed, then AI feedback is appended if the generator is enabled; an AI failure keeps rule-based feedback only (`backend/src/DevInsight.Application/Analyses/RunAnalysis.cs#RunAnalysis.AnalyzeAsync`, `backend/src/DevInsight.Application/Analyses/RunAnalysis.cs#RunAnalysis.GenerateAiFeedbackAsync`, `backend/src/DevInsight.Infrastructure/Ai/ClaudeFeedbackGenerator.cs#ClaudeFeedbackGenerator.GenerateAsync`).
7. Persistence: the analysis is added, the run marked `Succeeded` (or `Failed` with a truncated error), and both saved in one `SaveChangesAsync` (`backend/src/DevInsight.Infrastructure/Persistence/Stores/EfAnalysisStore.cs#EfAnalysisStore.Add`, `backend/src/DevInsight.Domain/Analyses/AnalysisRun.cs#AnalysisRun.Succeed`, `backend/src/DevInsight.Domain/Analyses/AnalysisRun.cs#AnalysisRun.Fail`, `backend/src/DevInsight.Infrastructure/Persistence/DevInsightDbContext.cs#DevInsightDbContext`).

### Scheduled re-analysis
1. Entrypoint: `ScheduledReanalysisService`, active when `Enabled` and `ScheduledReanalysisHours > 0` (default 24), ticks on a `PeriodicTimer` (`backend/src/DevInsight.Infrastructure/AnalysisRuns/AnalysisWorker.cs#ScheduledReanalysisService.ExecuteAsync`, `backend/src/DevInsight.Infrastructure/AnalysisRuns/AnalysisWorker.cs#AnalysisWorkerOptions`).
2. Each tick lists every user id and calls `RequestAnalysis.ExecuteForSelectedAsync` per user (`backend/src/DevInsight.Infrastructure/AnalysisRuns/AnalysisWorker.cs#ScheduledReanalysisService.ReanalyseAllAsync`, `backend/src/DevInsight.Infrastructure/Persistence/Stores/EfStores.cs#EfUserStore.ListIdsAsync`).
3. That queues both scopes for every selected repository through the same idempotent path, so the runs are then executed by `AnalysisWorker` as above (`backend/src/DevInsight.Application/Analyses/RequestAnalysis.cs#RequestAnalysis.ExecuteForSelectedAsync`).
4. The resulting analyses accumulate as score history, read oldest-first by `GetScoreHistoryAsync` (`backend/src/DevInsight.Infrastructure/Persistence/Stores/EfAnalysisStore.cs#EfAnalysisStore.GetScoreHistoryAsync`).
