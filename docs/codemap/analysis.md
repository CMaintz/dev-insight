## Purpose
Imports a user's GitHub repositories, lets them pick which ones count, and runs queued, scored analyses of those repositories with rule-based (and optionally AI) feedback (`backend/src/DevInsight.Application/Repositories/RepositoryUseCases.cs#ImportRepositories`, `backend/src/DevInsight.Application/Analyses/RequestAnalysis.cs#RequestAnalysis`, `backend/src/DevInsight.Application/Analyses/RunAnalysis.cs#RunAnalysis`). It also owns portfolio projects that group repositories (`backend/src/DevInsight.Application/Projects/ProjectUseCases.cs#ProjectUseCases`).

## Features
- Import or refresh repositories from GitHub, upserting by GitHub repo id: `POST /api/repos/import` (`backend/src/DevInsight.Api/Endpoints/ApiEndpoints.cs#ApiEndpoints.MapRepositories`, `backend/src/DevInsight.Application/Repositories/RepositoryUseCases.cs#ImportRepositories.ExecuteAsync`).
- List, get, and select or deselect a repository for the portfolio and aggregates: `GET /api/repos`, `GET /api/repos/{id}`, `PATCH /api/repos/{id}/select` (`backend/src/DevInsight.Application/Repositories/RepositoryUseCases.cs#RepositoryQueries`). New imports are selected only when the user owns them and they are not forks (`backend/src/DevInsight.Domain/Repositories/Repository.cs#Repository.Import`).
- Queue an analysis for one repository in a scope (`repo` or `user`), or both scopes for every selected repository: `POST /api/analysis/run/{repoId}`, `POST /api/analysis/run-all` (`backend/src/DevInsight.Api/Endpoints/ApiEndpoints.cs#ApiEndpoints.MapAnalysisRuns`, `backend/src/DevInsight.Api/Endpoints/ApiEndpoints.cs#ScopeParser.Parse`).
- Poll run status and list the 50 most recent runs: `GET /api/analysis/runs/{runId}`, `GET /api/analysis/runs` (`backend/src/DevInsight.Application/Analyses/AnalysisQueries.cs#AnalysisQueries.GetRunAsync`, `backend/src/DevInsight.Application/Analyses/AnalysisQueries.cs#AnalysisQueries.ListRecentRunsAsync`).
- Read the latest analysis, the score history, and an analysis's feedback: `GET /api/analysis/{repoId}`, `GET /api/analysis/{repoId}/history`, `GET /api/feedback/{analysisId}` (`backend/src/DevInsight.Api/Endpoints/ApiEndpoints.cs#ApiEndpoints.MapAnalysisResults`, `backend/src/DevInsight.Api/Endpoints/ApiEndpoints.cs#ApiEndpoints.MapInsights`, `backend/src/DevInsight.Application/Analyses/AnalysisQueries.cs#AnalysisQueries`).
- Create, edit, list and delete portfolio projects: `/api/projects` (`backend/src/DevInsight.Api/Endpoints/ApiEndpoints.cs#ApiEndpoints.MapProjects`, `backend/src/DevInsight.Application/Projects/ProjectUseCases.cs#ProjectUseCases`).
- UI: `/repositories` lists, filters and selects repositories and starts analyses (`frontend/src/app/features/repositories/repositories.page.ts#RepositoriesPage`, `frontend/src/app/features/repositories/repo-filter.ts#filterRepositories`); `/projects` edits projects (`frontend/src/app/features/projects/projects.page.ts#ProjectsPage`, `frontend/src/app/features/projects/project-form.ts#ProjectForm`); import and analyse-all buttons go through `frontend/src/app/core/analysis/workspace-actions.ts#WorkspaceActions`.
- All reads and writes are owner-scoped: a record of another user surfaces as not found (`backend/src/DevInsight.Application/Common/Errors.cs#Ownership.OwnedBy`).

## Owned entities
- `Repository`: an imported GitHub repository with metadata, languages and the `IsSelected` flag (`backend/src/DevInsight.Domain/Repositories/Repository.cs#Repository`), built from `backend/src/DevInsight.Domain/Repositories/GitHubRepositoryInfo.cs#GitHubRepositoryInfo`.
- `AnalysisRun`: a queued request with status `Queued -> Running -> Succeeded | Failed` and a link to the resulting analysis (`backend/src/DevInsight.Domain/Analyses/AnalysisRun.cs#AnalysisRun`, `backend/src/DevInsight.Domain/Analyses/AnalysisRun.cs#AnalysisRunStatus`).
- `Analysis`: an append-only snapshot of one repository in one scope with four scores, timeline and largest files (`backend/src/DevInsight.Domain/Analyses/Analysis.cs#Analysis`, `backend/src/DevInsight.Domain/Analyses/Enums.cs#AnalysisScope`), owning its `AnalysisMetric` rows (`backend/src/DevInsight.Domain/Analyses/AnalysisMetric.cs#AnalysisMetric`) and `Feedback` rows (`backend/src/DevInsight.Domain/Analyses/Feedback.cs#Feedback`).
- `Project`: a curated portfolio entry with name, description, up to 10 https image URLs and linked repository ids (`backend/src/DevInsight.Domain/Projects/Project.cs#Project`).
- All four are persisted through EF Core sets on `backend/src/DevInsight.Infrastructure/Persistence/DevInsightDbContext.cs#DevInsightDbContext`, configured in `backend/src/DevInsight.Infrastructure/Persistence/Configurations/EntityConfigurations.cs`.

## Happy paths

### Queue and execute an analysis
1. Entrypoint: the repo row's analyse button calls `frontend/src/app/features/repositories/repositories.page.ts#RepositoriesPage.analyse`, then `frontend/src/app/core/analysis/workspace-actions.ts#WorkspaceActions.analyseRepository`, then `frontend/src/app/core/analysis/run-tracker.ts#RunTracker.analyse`, which posts one run per scope (`repo` and `user`) via `frontend/src/app/core/api/analysis.api.ts#AnalysisApi.run` to `POST /api/analysis/run/{repoId}`, rate-limited to 30 per user per minute (`backend/src/DevInsight.Api/Endpoints/ApiEndpoints.cs#ApiEndpoints.MapAnalysisRuns`, `backend/src/DevInsight.Api/Infrastructure/ApiServices.cs`).
2. `backend/src/DevInsight.Application/Analyses/RequestAnalysis.cs#RequestAnalysis.ExecuteAsync` checks ownership, returns an existing queued or running run for the same repository and scope if there is one (`backend/src/DevInsight.Infrastructure/Persistence/Stores/EfStores.cs#EfAnalysisRunStore.FindUnfinishedAsync`), else creates `backend/src/DevInsight.Domain/Analyses/AnalysisRun.cs#AnalysisRun.Queue`, saves it, and writes the run id to the in-process channel (`backend/src/DevInsight.Infrastructure/AnalysisRuns/AnalysisWorker.cs#ChannelAnalysisQueue.EnqueueAsync`). The API answers 202 with the run (`backend/src/DevInsight.Api/Endpoints/ApiEndpoints.cs#ApiEndpoints.Accepted`).
3. `backend/src/DevInsight.Infrastructure/AnalysisRuns/AnalysisWorker.cs#AnalysisWorker` dequeues it (up to `MaxConcurrency` at once) and calls `backend/src/DevInsight.Application/Analyses/RunAnalysis.cs#RunAnalysis.ExecuteAsync`, which marks the run `Running` and saves (`backend/src/DevInsight.Domain/Analyses/AnalysisRun.cs#AnalysisRun.Start`).
4. `backend/src/DevInsight.Application/Analyses/RunAnalysis.cs#RunAnalysis.AnalyzeAsync` loads the repository, user and stored GitHub token, then clones the repository with the git CLI into a temp directory and reads its log and files (external: GitHub over git; `backend/src/DevInsight.Infrastructure/Git/GitSnapshotSource.cs#GitSnapshotSource.CaptureAsync`).
5. `backend/src/DevInsight.Domain/Analyses/Engine/AnalysisEngine.cs#AnalysisEngine.Analyze` filters commits and files to the scope and computes activity, commit-quality, structure and quality metrics; `backend/src/DevInsight.Domain/Analyses/Analysis.cs#Analysis.Create` weights them into an overall score (`backend/src/DevInsight.Domain/Analyses/Scoring.cs#Scoring.Overall`).
6. Feedback: `backend/src/DevInsight.Domain/Analyses/Rules/FeedbackRuleSet.cs#FeedbackRuleSet.Evaluate` adds rule-based items; when an API key is configured, `backend/src/DevInsight.Application/Analyses/RunAnalysis.cs#RunAnalysis.GenerateAiFeedbackAsync` adds AI items from Anthropic (external: `backend/src/DevInsight.Infrastructure/Ai/ClaudeFeedbackGenerator.cs#ClaudeFeedbackGenerator.GenerateAsync`), keeping rule feedback alone if that call fails.
7. Persistence: the analysis is added (`backend/src/DevInsight.Infrastructure/Persistence/Stores/EfAnalysisStore.cs#EfAnalysisStore.Add`), the run is marked `Succeeded` with the analysis id, or `Failed` with the error message, and both are saved in one `SaveChangesAsync` (`backend/src/DevInsight.Domain/Analyses/AnalysisRun.cs#AnalysisRun.Succeed`, `backend/src/DevInsight.Domain/Analyses/AnalysisRun.cs#AnalysisRun.Fail`).
8. Side effects on the client: `frontend/src/app/core/analysis/run-poller.ts#RunPoller.poll` hits `GET /api/analysis/runs/{runId}` every 2 s for at most 300 polls; `frontend/src/app/core/analysis/run-tracker.ts#RunTracker` toasts on failure or on losing track of a run.
9. Other triggers of the same flow: analyse-all posts to `POST /api/analysis/run-all` (`frontend/src/app/core/analysis/workspace-actions.ts#WorkspaceActions.analyseAllSelected`, `backend/src/DevInsight.Application/Analyses/RequestAnalysis.cs#RequestAnalysis.ExecuteForSelectedAsync`); `backend/src/DevInsight.Infrastructure/AnalysisRuns/AnalysisWorker.cs#ScheduledReanalysisService` queues every user's selected repositories on a timer (default 24 h); on startup, `backend/src/DevInsight.Infrastructure/AnalysisRuns/AnalysisWorker.cs#AnalysisWorker.RecoverUnfinishedRunsAsync` requeues queued or running runs left by a previous process.

### Import repositories from GitHub
1. Entrypoint: the import button calls `frontend/src/app/core/analysis/workspace-actions.ts#WorkspaceActions.importFromGitHub`, which posts via `frontend/src/app/core/api/repos.api.ts#ReposApi.importFromGitHub` to `POST /api/repos/import`, rate-limited to 5 per user per minute (`backend/src/DevInsight.Api/Endpoints/ApiEndpoints.cs#ApiEndpoints.MapRepositories`, `backend/src/DevInsight.Api/Infrastructure/ApiServices.cs`).
2. `backend/src/DevInsight.Application/Repositories/RepositoryUseCases.cs#ImportRepositories.ExecuteAsync` loads the user and stored GitHub token (throwing `backend/src/DevInsight.Application/Common/Errors.cs#PreconditionFailedException` if there is none), and lists the user's repositories from GitHub (external: `backend/src/DevInsight.Infrastructure/GitHub/OctokitGitHubGateway.cs#OctokitGitHubGateway.ListRepositoriesAsync`).
3. Each remote repository is refreshed if already imported, or created and added (`backend/src/DevInsight.Application/Repositories/RepositoryUseCases.cs#ImportRepositories.Upsert`, `backend/src/DevInsight.Domain/Repositories/Repository.cs#Repository.Refresh`, `backend/src/DevInsight.Domain/Repositories/Repository.cs#Repository.Import`).
4. Languages are fetched per repository, four at a time (external: `backend/src/DevInsight.Infrastructure/GitHub/OctokitGitHubGateway.cs#OctokitGitHubGateway.GetLanguagesAsync`), set on each repository, and everything is saved once (`backend/src/DevInsight.Application/Repositories/RepositoryUseCases.cs#ImportRepositories.FetchLanguagesAsync`).
5. Returns imported, updated and total counts (`backend/src/DevInsight.Application/Repositories/RepositoryUseCases.cs#ImportSummary`); the client shows a toast and bumps `importVersion`, which reloads the repository list (`frontend/src/app/core/analysis/workspace-actions.ts#WorkspaceActions.importFromGitHub`, `frontend/src/app/features/repositories/repositories.page.ts#RepositoriesPage`).

### Create or edit a portfolio project
1. Entrypoint: the form emits `save` (`frontend/src/app/features/projects/project-form.ts#ProjectForm`, `frontend/src/app/features/projects/project-form.model.ts#toProjectInput`) to `frontend/src/app/features/projects/projects.page.ts#ProjectsPage.save`, which calls `frontend/src/app/core/api/projects.api.ts#ProjectsApi.create` (`POST /api/projects`) or `frontend/src/app/core/api/projects.api.ts#ProjectsApi.update` (`PUT /api/projects/{id}`).
2. `backend/src/DevInsight.Application/Projects/ProjectUseCases.cs#ProjectUseCases.CreateAsync` and `backend/src/DevInsight.Application/Projects/ProjectUseCases.cs#ProjectUseCases.UpdateAsync` reject linked repository ids the user does not own (`backend/src/DevInsight.Application/Projects/ProjectUseCases.cs#ProjectUseCases.EnsureOwnRepositoriesAsync`).
3. `backend/src/DevInsight.Domain/Projects/Project.cs#Project.Update` validates name, image count and https image URLs and de-duplicates linked repositories; a new project is added (`backend/src/DevInsight.Infrastructure/Persistence/Stores/EfStores.cs#EfProjectStore.Add`) and the change is saved. No external side effects; the page updates its list and toasts (`frontend/src/app/features/projects/projects.page.ts#ProjectsPage.save`).

## Unknowns
- With the queue held in process memory (`backend/src/DevInsight.Infrastructure/AnalysisRuns/AnalysisWorker.cs#ChannelAnalysisQueue`), is the API ever run as more than one instance, and if so which instance executes a run queued on another?
- Can two concurrent requests for the same repository and scope both pass the unfinished-run check in `backend/src/DevInsight.Application/Analyses/RequestAnalysis.cs#RequestAnalysis.ExecuteAsync`? No unique constraint on unfinished runs was found in `backend/src/DevInsight.Infrastructure/Persistence/Configurations/EntityConfigurations.cs`.
- Is a repository ever removed when it disappears from GitHub? `backend/src/DevInsight.Application/Repositories/RepositoryUseCases.cs#ImportRepositories.ExecuteAsync` only upserts.
- What happens to a project's `LinkedRepositoryIds` when a linked repository row is deleted? The ids are a plain list on `backend/src/DevInsight.Domain/Projects/Project.cs#Project`, not a foreign key.
- Where is the GitHub token read by `backend/src/DevInsight.Application/Analyses/RunAnalysis.cs#RunAnalysis.AnalyzeAsync` written, and when is it refreshed? That happens outside this slice.
